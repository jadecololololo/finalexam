Apa yang dipelajari?

Di ekstrakurikuler ini, kamu akan diajak menyelami dunia teknologi dan pemrograman dari nol. Kami menyediakan lingkungan belajar yang interaktif untuk mengasah logika serta kreativitasmu dalam membangun sebuah website dari tahap dasar hingga menjadi halaman web yang utuh, responsif, dan menarik.

Kegiatan ini dirancang khusus untuk pemula. Berikut adalah materi intinya:

  • (Hypertext Markup Language): Mempelajari cara menyusun kerangka dan struktur dasar sebuah halaman web, seperti memasukkan teks, gambar, tabel, hingga form pendaftaran.
  • CSS (Cascading Style Sheets): Menghias tampilan website agar lebih estetis. Kita akan belajar mengatur warna, jenis huruf, tata letak (layouting), hingga membuat website yang responsif di layar HP maupun laptop.
  • JS (JavaScript): Memberikan 'nyawa' pada website. JavaScript digunakan untuk membuat elemen interaktif seperti animasi ringan, pop-up notifikasi, kalkulator mini, dan fitur dinamis lainnya.
  • Pengenalan Logika Python (Opsional): Dasar-dasar algoritma pemecahan masalah (problem solving) menggunakan bahasa Python yang mudah dipahami oleh pemula.
